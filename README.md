# Panacea Finance

Личная финансово-экономическая система для собственных решений и расчётов.

Проект сейчас создаётся **для личного использования**, а не как коммерческий сервис. Главные критерии — правильные расчёты, сохранность данных, удобство и скорость развития. Не нужны регистрация, сервер, подписки, облачная синхронизация и функции для нескольких пользователей.

## Запуск

Это статическое приложение. Открой GitHub Pages после публикации или запусти локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Текущие возможности

- Локальное хранение в IndexedDB через отдельный адаптер `src/data/indexeddb.js`.
- Раздельные счета и начальные остатки.
- Доходы и расходы с привязкой к счёту.
- Переводы между счетами без искажения доходов и расходов.
- Обзор капитала и история операций.
- Месячная аналитика: доходы, расходы, чистая разница и расходы по категориям.
- Цели накоплений.
- Калькулятор прибыли и маржинальности.
- Сценарий переезда: стартовые расходы, ежемесячный бюджет и резерв безопасности.
- Экспорт и импорт резервной копии JSON.

## Принципы проекта

- Локальное хранение без сервера и отправки финансовых данных.
- Сначала надёжность и полезность для владельца, затем новые функции.
- Не смешивать выручку, прибыль, расходы, остатки и переводы.
- Не усложнять стек без практической причины.
- Развивать проект отдельными ветками, сохраняя `main` стабильной.

Подробные правила разработки находятся в [AGENTS.md](./AGENTS.md). План архитектуры и перехода к Windows-приложению — в [ARCHITECTURE.md](./ARCHITECTURE.md).

## Важно о данных

Данные хранятся в браузере и на конкретном устройстве. Очистка данных сайта или потеря устройства может привести к потере записей. Регулярно сохраняй JSON-резервную копию в отдельное место. Приложение не подключается к банкам и не отправляет данные на сервер.


## Development checks

The financial calculation module is isolated in `src/core/finance.js` and has dependency-free unit tests. With Node.js 20 or newer installed, run:

```bash
npm test
```
