# Panacea Finance — версия 0.2

Личная финансово-экономическая система. Статический сайт, без сервера и облачной синхронизации.

## Запуск
Открой GitHub Pages после публикации или запусти локально:
```bash
python -m http.server 8000
```

## Возможности
- Локальное хранение в IndexedDB.
- Раздельные счета и начальные остатки.
- Доходы и расходы с привязкой к счёту.
- Переводы между счетами без искажения доходов/расходов.
- Обзор капитала и история операций.
- Цели накоплений, включая переезд.
- Калькулятор прибыли и маржинальности.
- Экспорт и импорт резервной копии JSON.

## Важно
Данные остаются в конкретном браузере и на конкретном устройстве. Очистка данных браузера может удалить записи. Регулярно экспортируй резервную копию. Приложение не подключается к банкам и не отправляет данные на сервер.
